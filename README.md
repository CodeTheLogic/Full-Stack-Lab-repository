# 📘 Assignment 06 - REST API using Node.js and Express

## 🎯 Aim
Develop a set of REST API using Express and Node.

## 📌 Objectives
- Define HTTP GET and POST operations  
- Understand REST, REST endpoints, API Integration, and API Invocation  
- Use a REST Client to make POST and GET requests  

## 📝 Description
This project demonstrates the development of a REST API using Node.js and Express. The API performs operations such as adding and retrieving book records using HTTP methods like GET and POST. It helps in understanding how client-server communication works in backend development.

## 🛠️ Technologies Used
- Node.js  
- Express.js  
- Postman / REST Client
